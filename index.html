나이스 교육정보 개방 포털 API 만들기

급식 정보를 불러오기 위한 인증키 발급 순서입니다.

  1. https://open.neis.go.kr 접속
  2. 로그인
  3. 개인정보동의
  4. 마이페이지
  5. 인증키발급
  6. 개인정보 입력 및 인증키 발급 신청
  7. 인증키 복사
복사한 인증키를 설정창의 `나이스 API 키` 칸에 붙여 넣으면 급식 정보 조회에 바로 사용할 수 있습니다.

학교 위도·경도 넣는 방법

날씨와 미세먼지 정보를 정확히 가져오기 위한 좌표 입력 방법입니다.

  1. 구글 AI 모드
  2. `000학교 위도, 경도` 검색
  3. 숫자 복사해서 설정 화면에 붙여넣기
학교명을 넣어 위도·경도를 검색한 뒤, 위도는 `학교 위도`, 경도는 `학교 경도` 칸에 각각 넣으면 됩니다.
